================================================

프로젝트 소개, 지원 범위, 빠른 시작: README.md
설치·검증·업데이트·백업 절차: DEPLOYMENT.txt
Hermes 출처와 유지 패치, 의존 구성요소 고지: UPSTREAM.txt
Forsic MIT 라이선스: LICENSE / 제3자 고지: THIRD_PARTY_NOTICES.txt

Linux 새 설치: python3 setup_forsic.py
안내에 따라 의존성과 두 네이티브 화면을 준비한 뒤 python3 run.py로 실행합니다.
브라우저의 처음 설정에서 LLM·증거 폴더·접속 방식을 정하고 서버를 다시 시작합니다.
수동 설치·Docker 분석 도구·온라인 TLS 프록시는 DEPLOYMENT.txt를 따르세요.
웹 앱은 Linux 호스트에서, 분석 도구는 별도 격리 컨테이너에서 실행합니다.

대화: http://127.0.0.1:8860/chat
조사 보드: http://127.0.0.1:8860/forsic

기존 state/가 있는 설치에 init을 다시 실행하지 않습니다. 원본 증거,
세션·노트·보고서·비밀 설정은 로컬에 보관하며 공개 소스에 넣지 않습니다.
활성 조사 중 소스를 교체하거나 서버를 재시작하지 않습니다.

보고서 파일 생성·실행 종료·분석 완료는 서로 다릅니다. 확인 사실과
미확인 범위, 경쟁 설명을 함께 검토하고 최종 판단은 사람이 합니다.

온라인 접속에는 소유한 HTTPS 도메인·TLS 프록시·네이티브 로그인이 필요합니다.
신뢰 사설망 무로그인 모드는 인터넷에 공개하지 않습니다. 사용자별 사건 격리는
제공하지 않습니다. 보안 안내와 제보 방법: SECURITY.md
