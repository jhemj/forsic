Separately installed dependencies
--------------------------------
The source release contains dependency declarations, not the installed runtime
or parser image. Installation obtains components under their own terms, including:

- python-docx 1.2.0, lxml 6.1.3 and python-telegram-bot 22.8, declared in
  forsic_plugin/plugin.yaml and requirements-forsic.txt.
- dissect.target 3.25.1 and dissect.xfs 3.13 in the Python 3.12-based parser image,
  declared in Dockerfile.tools.
- Hermes-managed Python/Node tools and transitive packages, identified by the
  pinned PM, Python and frontend lockfiles under upstream/hermes/.
- Host utilities such as libewf, Docker and their dependencies, installed by the
  operator rather than included as Forsic binaries.

Consult each installed distribution's license and notices, including those of
bundled libraries and container base packages. When distributing a built runtime
or image, retain the notices and satisfy any additional obligations for the actual
components included; the Forsic MIT license is not a substitute for those terms.
This summary is not a full software bill of materials or a license compatibility
certification for every possible installation.
