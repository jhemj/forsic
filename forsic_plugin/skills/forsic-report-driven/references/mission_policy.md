# 미션 선택·종결의 짧은 규칙

보고서의 중요한 질문·답·반론·공백을 읽은 뒤 미션을 선택한다. 전체 보고서를 매번 재작성하지 않는다. 다음은 의미 우선순위이며 고정 확률 점수가 아니다.

1. 현재 답을 뒤집거나 범위를 바꿀 반론·정정·반환 결과를 먼저 확인한다.
2. 이미 반환됐고 정확 조건과 필요한 원문이 있는 검사는 새 수집보다 먼저 평가할 수 있다.
3. 내부 참조·schema·본문 제시 오류는 내부 복구로 분류한다. 외부 자료 부족으로 바꾸지 않는다.
4. 중요성 미평가 후보는 낮은 중요도로 확정하지 않는다. 적용성 검토·대기 승격으로 기회를 준다.
5. 같은 물리 결과·조건을 반복해서 해석하지 않는다. 새 명제·반론·객체·구간이면 새 논리 평가를 허용한다.
6. 관측을 확인하고 독립 정황·경쟁 설명으로 가장 유력한 답과 신뢰도를 판단한다. 직접 증거 부재만으로 모든 추론을 보류하지 않으며 없는 사실을 채우지 않는다.
7. 범위 한정 정상 종결은 근거·재검토 조건으로 보존한다. 새로운 반증이 없으면 원문을 재수집하지 않는다. 미검토·자료 부족·예산 보류는 정상과 구별한다.
8. 신뢰도와 조사 우선순위는 별개다. 다음 검사가 설명의 순위·영향 범위에 줄 변화와 비용을 비교한다. 정황 개수나 고정 점수로 종결하지 않는다.
9. 원문·관련성·판단·행위 횟수를 같은 수치로 합치지 않는다.
10. 편집·쪽수·레이아웃 결함은 조사 미션과 분리한다.

## 선택적인 계획

일반 읽기·검색·판단 저장에는 미션이 필요 없다. 자료를 본 뒤 선택한 근거를 현재 질문의 judgment에
직접 연결한다. 사후 미션을 만들어야 답을 저장할 수 있는 것은 아니다.

결과를 보기 전에 판별 조건·정확한 입력을 보존할 가치가 있으면 forsic_mission을 사용한다.
선택한 미션의 next_call을 실행하고, 실제 반환과 citation_refs를 forsic_assess에서 한 번에 평가한다.
버전·좌표는 프로그램이 검증한다. 국소 평가가 전체 질문을 자동 종결하거나 의미 정확성을 승인하지 않는다.
예산·권한은 계획 저장으로 생기지 않는다. 실패·미반환은 무검색 결과로 바꾸지 않는다.

## 종료

조사 범위 충족과 판단 확실성은 별개다. 불확실한 답으로도 의미 있는 검사를 마친 범위는 종결할 수 있다. 가능한 중요한 검사 또는 미검토 반론이 남으면 조사 범위 완료가 아니다. 자료·지원 능력 때문에 더 판별할 수 없는 경우는 해당 범위를 종결할 수 있으나 왜 불가능한지와 재개 조건을 남긴다. 예산 때문에 못 한 검사는 미검토 보류다. 보고서는 언제든 유효한 부분 스냅샷으로 만들 수 있지만 승인·배포는 별도다.
