# 미션 선택·종결의 짧은 규칙

보고서의 중요한 질문·답·반론·공백을 읽은 뒤 미션을 선택한다. 전체 보고서를 매번 재작성하지 않는다. 다음은 의미 우선순위이며 고정 확률 점수가 아니다.

1. 현재 답을 뒤집거나 범위를 바꿀 반론·정정·반환 결과를 먼저 확인한다.
2. 이미 반환됐고 정확 조건과 필요한 원문이 있는 검사는 새 수집보다 먼저 평가할 수 있다.
3. 내부 참조·schema·본문 제시 오류는 내부 복구로 분류한다. 외부 자료 부족으로 바꾸지 않는다.
4. 중요성 미평가 후보는 낮은 중요도로 확정하지 않는다. 적용성 검토·대기 승격으로 기회를 준다.
5. 같은 물리 결과·조건을 반복해서 해석하지 않는다. 새 명제·반론·객체·구간이면 새 논리 평가를 허용한다.
6. 원문을 충분히 보지 못한 상태에서 비교·정상·침해를 단정하지 않는다.
7. 원문·관련성·판단·행위 횟수를 같은 수치로 합치지 않는다.
8. 편집·쪽수·레이아웃 결함은 조사 미션과 분리한다.

## 실행 전 미션 확인

질문·원의무·대상 명제·실제 도구 능력·정확 입력 버전·관측 범위·지지/반박/판별 불가 조건·반론·비용·재시도 차이·완료 증명을 확인한다. 예산·권한·도구가 미제공이면 실행 예정으로 말하지 않는다. 제안한 `proposed_tool_name`은 실제 도구 목록에서 해석한 뒤에만 사용한다.

## 미션 결과

실제 반환 → 필요한 원문 제시 → 검사별 조건 평가 → 범위/인용 검증 → 독립 채택 → 질문 답 변경 또는 근거 있는 미결 → 보고서 갱신.

새 계약·새 ID·요약 갱신·입력 축약만으로 원래 조사 의무가 해결되지는 않는다. 복구는 원래 의무에 연결된 유효 평가와 남은 공백을 기준으로 기록한다.

## 종료

가능한 중요한 검사 또는 미검토 반론이 남으면 조사 범위 완료가 아니다. 자료·지원 능력 때문에 더 판별할 수 없는 경우는 해당 범위를 종결할 수 있으나 왜 불가능한지와 재개 조건을 남긴다. 예산 때문에 못 한 검사는 미검토 보류다. 보고서는 언제든 유효한 부분 스냅샷으로 만들 수 있지만 승인·배포는 별도다.
