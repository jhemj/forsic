# Wording, presentation, and design contract

- Integrated report body: aim for about 3 A4 pages. Current answer → entry and actions → information impact and evidence → main sequence. Keep core uncertainty in the relevant assessment sentence. Do not fill pages by rephrasing the same proposition.
- Do not write management decisions or response recommendations. People make management decisions; reports provide facts, analytical judgments, confidence, evidence, uncertainty, and further investigation.
- Appendix in the same document: questions, evidence, discriminating checks, counterarguments, full limitations, execution, hashes, corrections, and reproduction paths. Appendix length is unrestricted.
- Create one integrated HTML/Word pair with the same adopted claims, important limitations, and snapshot. Use short evidence numbers in the body; place exact internal references and detailed history in the same document's appendix. Templates are not case evidence.
- Use black body text, gray table headers, thin rules, and Noto Sans CJK KR or an approved substitute. Do not add large Forsic illustrations or staged activity to reports.
- Use the shared style: 11pt body, 10pt tables, A4 margins of 18mm top/bottom and 20mm left/right. Do not meet the page target by deleting limitations or excessively shrinking text.
- Express unconfirmed findings, conflicts, and corrections in text. Do not express conclusions through red color or probabilities alone.

## Exact Korean sentence patterns

Confirmed fact: “[대상]의 [기록 종류]에 [내용]이 기록되어 있음. [F/O 참조]”
Analytical judgment: “[설명]이 현재 가장 유력함. [독립 근거와 경쟁 설명 비교]로 신뢰도는 [질적 평가]. [중요 공백/반증] 때문에 [확정하지 못한 범위]는 남음.”
Indistinguishable explanations: “[관측]은 [경쟁 설명들]을 가르지 못함. [가능한 다음 검사 또는 재검토 조건].”
Benign alternative: “[정상 설명]도 가능하며 [어떤 자료]로 구별할 수 있음.”
Material request: “[질문]을 판별하려면 [최소 자료 범위]가 필요함. 현재 보유 자료·도구로는 [이유] 때문에 확인 불가.”
Actual action: “[실행 기록]에서 [조치] 수행을 확인. [결과·범위].”
Further investigation: “[미확인 질문]을 구별하려면 [자료·검사]가 필요하며 [결과 조건]을 확인한다.”

## Prohibited shortcuts

Command record → execution success; account → actual person; private address → corporate/attacker ownership;
hash difference → malicious tampering; no result → no activity; file ctime → creation/execution time;
recommendation → completed response; model score → compromise probability.

## Forsic

Current work reflects actual request state; prior results reflect actually adopted results. Even when reading
past work, keep current execution and color tied to the latest valid scope. Explain purpose, evidence,
expected discrimination, and limitations instead of exposing full internal reasoning.
