# 문체·표시·디자인 계약

- 임원용: A4 2~3쪽 목표, 기본 3쪽. 현재 답 → 확인된 영향 → 경과·반론 → 남은 조사. 같은 명제의 변형으로 지면을 채우지 않는다.
- 경영 의사결정·대응 권고는 작성하지 않는다. 경영 결정은 사람이 하며 보고서는 사실·분석 판단과 신뢰도·근거·불확실성·추가 조사를 제공한다.
- 실무자용: 질문·근거·판별·반론·공백·재현 경로. 12쪽은 양식 예일 뿐 결과 길이 제한이 아니다.
- 같은 F-번호·채택 주장·중요 한계·스냅샷을 두 reader에 공유한다. HTML/Word는 같은 reader view에서 렌더링한다.
- 검정 본문, 회색 표 머리글, 얇은 선, Noto Sans CJK KR 또는 승인된 대체 폰트. 보고서에 포식이 대형 그림·작업 연출을 넣지 않는다.
- 본문 10.3~11pt, 표 9.5pt 권장. 한계를 삭제하거나 글자를 과도하게 줄여 쪽수 목표를 맞추지 않는다.
- 미확인·상충·정정은 텍스트로 표시한다. 빨강이나 확률만으로 결론을 나타내지 않는다.

## 정확한 문형

확인 사실: “[대상]의 [기록 종류]에 [내용]이 기록되어 있음. [F/O 참조]”
분석 판단: “[설명]이 현재 가장 유력함. [독립 근거와 경쟁 설명 비교]로 신뢰도는 [질적 평가]. [중요 공백/반증] 때문에 [확정하지 못한 범위]는 남음.”
구별 불가: “[관측]은 [경쟁 설명들]을 가르지 못함. [가능한 다음 검사 또는 재검토 조건].”
정상 대안: “[정상 설명]도 가능하며 [어떤 자료]로 구별할 수 있음.”
자료 요청: “[질문]을 판별하려면 [최소 자료 범위]가 필요함. 현재 보유 자료·도구로는 [이유] 때문에 확인 불가.”
실제 조치: “[실행 기록]에서 [조치] 수행을 확인. [결과·범위].”
추가 조사: “[미확인 질문]을 구별하려면 [자료·검사]가 필요하며 [결과 조건]을 확인한다.”

## 금지되는 축약

명령 기록→실행 성공, 계정→실제 사람, 사설주소→사내/공격자 소유, 해시 차이→악성 변조, 무결과→행위 없음, 파일 ctime→생성/실행시각, 권고→대응 완료, Jev 점수→침해 확률.

## 포식이

현재 작업은 실제 요청 상태, 이전 결과는 실제 채택 결과다. 과거 작업을 읽어도 현재 실행·색은 최신 유효 범위를 유지한다. 내부 사고 전문 대신 목적·근거·예상 판별·한계를 설명한다.
