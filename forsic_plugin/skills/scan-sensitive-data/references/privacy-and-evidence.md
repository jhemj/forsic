# Safe investigation and local evidence

Treat every value and surrounding context as potentially sensitive and untrusted. Tool/model results are safe
candidate metadata, opaque identifiers, locations, bounded masked previews and coverage. A value-group ID uses
case-local keyed grouping, not a public digest of a short phone/identifier. Group IDs cannot be compared across
cases or changed keys. Never reconstruct originals from masked output or dump scanner JSON/stderr/base64.

The host preserves private raw scan material separately from generic source lookup and evidence export. The
local report renderer hydrates bounded originals only after the safe judgment snapshot is stored, and only for
sources in the selected report. The integrated HTML and Word appendix includes finding/input/source identity,
version, original locator, encoding, excerpt/match byte ranges and omissions. Original-file bytes and retained
UTF-8 scalar coordinates are different coordinate spaces. Preserve that distinction and all decoding limits.

The report manifest/tool summary contains counts and local-only policy, not the original excerpts. Automatic
Telegram document synchronization rejects the entire local-only report bundle. Local browser download is still
available. Main prose, question notes, reviewer inputs, general logs and selected-evidence exports remain safe.
Never describe a partial appendix as the complete raw scan or the whole evidence population.
