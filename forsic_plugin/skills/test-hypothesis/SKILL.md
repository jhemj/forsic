# 가설 판단과 다음 검사

현재 질문에 가장 유력한 설명과 이를 뒤집을 현실적인 경쟁 설명을 짧게 적는다. 모든 상상 가능한 대안을
나열하지 않는다. 핵심 관측·출처·추정 연결·반론을 비교해 현재 답을 선택한다. 직접 증거가 부족해도 분석
판단은 가능하다. '관측 확인', '개연성 높은 해석', '서로 구별 어려움'은 서로 다른 의미다.

## 신뢰도와 조사 가치

출처의 품질·수집 범위·단서의 독립성·경쟁 설명 대비 설명력·상충 근거를 근거로 질적 신뢰도를 설명한다.
보정되지 않은 확률 숫자나 정황 개수를 쓰지 않는다. 같은 원문에서 파생한 요약·노트·보고서는 독립 증거가 아니다.
정상/악성 모두 가능한 관측도 상대적으로 어느 설명에서 더 자연스러운지 맥락을 비교할 수 있다. 둘에
비슷하게 예상되는 결과만으로 순위를 올리지 않는다. 직접 기록이 없는 연결은 추론으로 표시한다.

신뢰도는 조사 우선순위와 별개다. 약한 단서라도 영향이 크거나 적은 비용으로 확인할 수 있으면 적극
조사한다. 실행 전에 '각 결과가 나오면 현재 답이나 다음 행동이 어떻게 달라지는가?'를 짧게 정한다.
대안의 순위를 가르거나 범위를 좁힐 검사를 고른다. 모든 단서를 같은 깊이로 조사하지 않는다.

## 결과와 공백의 의미

명령/설정의 존재, 실행, 성공한 효과, 행위자·승인은 각각 판단한다. 한 단계의 관측으로 나머지를 자동
확정하지 않는다. 여러 독립 정황이 연결을 지지하면 유력한 추론으로 제시할 수 있지만 관측하지 않은
속성·시각·출력·신원은 만들어 채우지 않는다. 이름이나 익숙한 경로 자체는 기능·승인의 검증이 아니다.

무결과는 검사 대상·기간·표현·남은 페이지와 기록 능력 안에서 평가한다. 로그가 없으면 원래 생성 여부,
취득 범위, 정상 회전/보존을 먼저 살핀다. 선택적 공백·관련 설정·다른 잔존 흔적의 조합은 가설 순위를
바꿀 수 있다. 파일 미발견만으로 과거 존재·삭제·은폐 의도까지 확정하지 않는다. 기록 공백은 공격의
반증도 자동 입증도 아니다. 더 회수하기 어렵다면 판별 가능한 다른 자료로 전환한다.

결과를 받으면 기존 반증을 함께 비교해 답·신뢰도·다음 검사를 갱신한다. 이미 성공한 결과와 원문은
재사용한다. 판단 변화가 없는 재검색은 줄인다. 정상 설명이 충분하고 남은 검사의 가치가 낮으면
forensic-investigation에 따라 범위를 정해 종결한다. 자료 부족·미검토는 정상 판정과 구별한다.
새로운 반증이 나오면 종결한 범위도 다시 검토한다. 가설 종결은 원문 삭제가 아니다.
