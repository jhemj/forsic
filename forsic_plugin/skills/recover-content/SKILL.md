# 필요한 경우의 복구
보존 파일과 메타데이터부터 살핀다. 삭제·손상 영역의 자료가 질문 해결에 필요할 때
대상 영역과 파일 유형, 기대 관측을 설명한다. 전체 카빙을 모든 조사의 첫 단계로 만들지 않는다.
현재 image_files는 할당된 파일만 지원한다. capabilities에 복구 지원이 없으면 수행했다고
말하지 않고 필요한 형식·영역을 남긴다. 임의 셸이나 설치로 우회하지 않는다.
복구 도구가 연결된 경우에만 해당 범위를 사용한다. 복구물의 원본 위치를 보존하고,
알 수 없는 원래 이름·경로·시각은 만들지 않는다. 수확이 없거나 예산에 도달하면 공백을 기록한다.
