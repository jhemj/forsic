# 최초 진입 경로 좁히기

가장 이른 의심 흔적은 조사 시작점이지 최초 침입의 확정 시점이 아니다. 현재 질문·증거 기간과
이미 확인한 답을 읽고, 가능한 진입 설명을 구별할 자료를 선택한다.

인증 성공/실패와 세션, 노출 서비스의 접근·오류 기록, 계정/키 변경, 초기 파일 생성·실행 흔적을
실제로 존재하는 범위에서 대조한다. 운영체제·서비스에 맞는 자료만 선택하며 자료 경로를 지어내지 않는다.
로그 회전·보존 시작·시간대·시계 불일치를 확인하고, 앞선 기록 부재를 앞선 침입 부재로 쓰지 않는다.

- 인증 실패는 진입 성공이 아니다. 성공도 승인된 정상 관리 작업일 수 있다.
- 취약 버전·공격 문자열은 실제 악용 성공이 아니다. 서버 측 효과나 연계된 실행/파일 흔적이 필요하다.
- 자동실행 설정·악성 파일 존재는 지속성 또는 보유 흔적일 수 있으며 최초 경로를 직접 입증하지 않는다.
- 동일 IP·계정·파일명만으로 사건을 연결하지 않는다. 세션/호스트/대상/시각의 일치와 불일치를 기록한다.

확인된 시각은 correlate-time으로 원문을 연결하고, 관련 지표는 organize-indicators로 정리한다.
답은 '최초 확인 시점 / 가능한 경로 / 지지 근거 / 경쟁 설명 / 다음 판별'로 간결히 남긴다.
기존 도구로 구별 가능한 다음 검사를 미션으로 수행하고, 자료가 없으면 범위 내 미확인으로 보고한다.
발견한 서비스 주소에 접속하거나 재현 공격·자격정보 사용을 시작하지 않는다.
