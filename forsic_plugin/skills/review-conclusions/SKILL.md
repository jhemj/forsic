# 결론 검토

새로운 중요 주장을 채택하거나 범위를 종결하기 전에, 바뀐 판단만 짧게 대조한다. 기존 Hermes 조사 턴에서
수행하며 별도 검토 모델·반복 루프를 만들지 않는다. 같은 정의·근거·반론의 검토를 반복하지 않는다.
직접 입증이 부족해도 정황의 설명력을 비교해 가장 유력한 판단을 내린다. 검토는 모든 답을 미상으로 돌리는 절차가 아니다.

## 주장 하나의 관측 → 추론 → 판별

1. **원문 관측:** 현재 근거 ID와 정확 필드에 무엇이 반환됐는지 한 문장으로 적는다. 입력한 검색어·명령·
   검사 대상과 실제 출력·검출 결과를 분리한다. 조사자가 무엇을 찾으려 했는지는 무엇을 발견했는지와 다르다.
   명령 문자열의 프로그램명·인자는 대상 파일의 내용·종류·실행 성공을 증명하지 않는다. 해당 반환이 없으면 만들어 쓰지 않는다.
2. **적용 범위:** 도구가 실제 판별한 속성, 파일·기간·바이트 범위, 건너뜀·오류·계속 읽기 위치를 확인한다.
   내용 검색은 이름 목록 조회가 아니며, 방문한 파일 수는 읽기를 완료한 파일 수가 아니다. 미검사·미지원 자료는
   미상으로 남긴다. 필요한 속성을 확인하는 기존 조회로 전환하거나 그 검사의 추가 가치가 낮은 이유를 남긴다.
3. **최선의 설명:** 관측 사이에 필요한 가정을 드러내고 가장 강한 현실적 경쟁 설명과 비교한다. 의심 경로·설정과
   조사·정리 명령의 조합은 침해 의심을 강화할 수 있으나 특정 악성코드 계열·정화 성공·승인된 운영자까지 한꺼번에
   확정하지 않는다. 과거의 조사자가 의심한 대상이라는 사실과 그 의심이 맞았다는 판단도 구분한다.
4. **다음 판별:** 어떤 관측이 설명 순위·영향·행동을 바꿀지 정한다. 이미 반환된 원문이면 재사용한다.
   의미 있는 검사가 소진됐다면 추정 연결·잔여 불확실성과 함께 범위 한정으로 답한다. 단순히 가능한 모든 검사를 요구하지 않는다.

원문이 현재 문맥에 없거나 인용이 의심되면 forsic_reporting(source)로 필요한 필드만 읽는다. 노트·요약·
보고서·같은 자료의 반복 조회는 독립 증거가 아니다. 인용 목록에 ID가 존재하는 것과 그 원문이 해당 주장을
지지하는 것은 다르다. 핵심 문장별 연결을 확인한 뒤 evidence_ids를 현재 근거에 맞게 갱신한다.

## 시각·행위·귀속

시각은 원래 필드의 뜻과 정밀도를 유지한다. 파일 접근/변경 시각은 그 자체로 특정 명령의 마지막 실행이나
특정 줄의 작성 시각이 아니다. 과거 상태 변화에는 별도 변경·실행 근거가 필요하다. 시간축이 판단에 중요하면
correlate-time으로 원시 시각·연도·시간대와 경쟁 설명을 대조한다. 없는 연도나 시각을 보충하지 않는다.

관측된 명령, 실제 실행, 성공, 효과, 승인, 행위자 귀속은 별도 연결이다. 독립 잔존 효과가 실행을 지지하면
추론으로 제시하되 반환되지 않은 성공 결과를 관측으로 쓰지 않는다. 내부 주소·관리 도구·규칙적 자동화는
승인을 보증하지 않는다. 공격·운영·복구 활동이 같은 계정에서 섞이거나 활동 중 변할 가능성도 비교한다.
출처 신뢰성과 반론을 고려하되 모든 상상 가능한 대안을 소진할 필요는 없다.

## 정정과 전달

핵심 과잉 단정이 발견되면 그 주장을 보류하고, 확인된 관측·유력한 추론·철회할 연결을 현재 질문에 정정한다.
같은 question_id/current expected_revision과 correction_reason을 사용하고 scope를 표현 정리 때문에 바꾸지 않는다.
명제·범위 변경은 기존 미션 적용성에 영향을 준다. 실제 질문이 다르면 별도 질문으로 관리한다.
저장 성공 영수증을 확인하고 제목·요약·시간축도 같은 신뢰도와 범위로 맞춘다. 과거 기록과 원문은 보존한다.

정정 전 보고서는 보존된 이전 판단이지 검증된 최신 결과가 아니다. 기존 보고서의 문장을 원문 대신 재인용하지 않는다.
forsic-report-driven에 따라 실제 결과 평가와 최신 답을 연결하고 바뀐 snapshot만 render한다. 저장·참조 검증은
해석 승인과 다르며, 선택적 review의 미실행·실패·stale도 통과가 아니다.

종료 때는 중요한 질문별로 가능한 판별, 미평가 결과, 내부 차단, 외부 의존, 낮은 추가 가치의 처분을 확인한다.
한 질문의 차단은 전체 차단이 아니다. 파일 생성은 조사 완료가 아니며, 미검토·실패·예산 종료를 숨기지 않는다.
