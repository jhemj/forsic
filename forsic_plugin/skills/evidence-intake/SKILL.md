# 증거 접수
forsic_case에서 질문과 범위를 확인하고 기존 접수 결과를 재사용한다. forsic_list로
자료를 찾고 E01은 image_info, image_files(action=volumes)로 형식과 볼륨을 확인한다.
hash는 현재 SHA-256이며 취득 당시 검증값과 비교하기 전에는 취득 무결성 증명이 아니다.
forsic_verify action=start는 ewfverify를 한 번 백그라운드 실행하고 즉시 상태를 돌려준다.
같은 입력은 실행 중 작업이나 완료 결과를 재사용한다. 다른 질문을 조사한 뒤
action=status와 같은 path로 완료 여부를 확인한다. 짧은 간격으로 상태만 반복 조회하지 않는다.
검사 진행/실패/중단 불명은 완료가 아니다. 타임아웃 예산은 운영자 설정이며 모델이
같은 실패를 새 작업으로 무작정 재시작하지 않는다. 필요한 예산 변경은 사용자에게 설명한다.
SUCCESS여도 취득 당시 비교용 해시가 없으면 그 검사가 확인한 범위만 설명한다.
누락 세그먼트, 암호화, 미지원 형식, 검증 실패를 구별하고 읽지 못한 영역을 없다고 쓰지 않는다.
