# 중요한 조사 알림

기존 Telegram 미러는 다음 항목만 전송한다.

- Hermes `clarify`를 통한 사용자 확인 요청. 이미 응답하거나 취소한 요청은 보내지 않는다.
- 채택 근거가 연결된 중요 질문의 답·평가 변경과 변경 이유.
- 관측한 native 목표의 완료 또는 일시정지 전환.

질문의 답은 웹 확인 요청에서 입력한다. 기존 Telegram 멘션은 대화에 전달되지만,
대기 중인 웹 확인 요청의 답으로 자동 변환하지 않는다.
일반 대화, 내부 조사 질문, 도구 시작·반환, 압축·진행 표시와 입력 중 표시는 전송하지 않는다.
완료 알림은 native 상태의 통지이며 보고서의 정확성을 검증했다는 뜻이 아니다.

정책을 처음 적용할 때 현재 상태부터 관측하며 과거 대화를 재분류하거나 재전송하지 않는다.
이전 전송 미확정 기록과 mention offset은 보존한다. 새 중요 알림에도 전송 영수증을 먼저 저장하며,
반환을 확인하지 못한 전송은 자동으로 재시도하지 않는다. 오래된 사건 연결 오류는 해당 경로에 격리한다.
관측 사이에 끝난 짧은 상태 전환은 알림에서 누락될 수 있다. 세부 기록은 웹과 원장에 남는다.

기존 수신 그룹과 자격정보 가림·텍스트 전송 경계를 유지한다. 보고서 파일 첨부는 기존 별도 opt-in 설정을
따르며, 민감 원문을 로컬로 제한하는 정책을 변경하지 않는다.
