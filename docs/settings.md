# 설정 화면

좌측 하단 **설정**에서 연결과 분석 환경을 함께 관리합니다. 설정 항목을 바꿔도 화면을 떠나기 전까지 입력 중인 값은 유지됩니다. 저장 버튼 또는 변경 검토의 실행 버튼을 눌러야 실제로 반영됩니다.

## 기본 설정

- **조사·검토 모델**: 포식이의 모델 연결과 렌 전용 모델을 설정합니다. API 키는 선택 항목이며, 키 없이 사용하도록 선택하면 빈 값으로 저장합니다. 등록된 키는 화면에 다시 표시하지 않습니다. 문맥 길이는 고급 설정에서 조절할 수 있습니다.
- **자료 폴더·접속**: 자료 폴더, 접속 범위, 필요한 로그인 설정을 단계별로 검토합니다. 이 화면은 모델 설정을 중복 편집하지 않으며 저장 시 최근에 저장된 모델 연결을 유지합니다.
- **외부 조회**: VT / GTI 조회와 공개 IP·도메인 조회 허용 여부를 설정합니다. 실제 외부 연결 확인은 버튼을 눌렀을 때만 수행합니다.
- **텔레그램 알림**: 그룹과 봇 토큰을 설정합니다. 저장만으로 메시지를 보내거나 기존 사건 토픽을 옮기지 않습니다.

주 모델은 저장 즉시 새 조사에 적용됩니다. 진행 중인 조사는 현재 대화 차례를 마친 뒤 Hermes가 다음 차례 시작 시 연결·모델·키를 함께 갱신합니다. 개별 대화에서 지정한 모델은 Hermes의 기존 프로필 추종·고정 규칙을 따릅니다. 렌 모델은 다음 검토 호출부터, 접속 범위는 다음 서버 시작부터 적용됩니다. 각 화면의 적용 안내와 현재 상태를 확인하세요. 원격 접속에서는 기존 읽기 전용 범위를 유지하며, 설정 변경은 호스트 PC에서 수행합니다.

모델 카드의 **연결 테스트**는 저장 전 입력한 주소·모델·키로 짧은 응답을 요청합니다. 버튼을 눌렀을 때만 호출하고 설정은 저장하지 않으며 사건 자료는 포함하지 않습니다. 등록된 키를 유지하면 같은 연결에만 사용하고, 빈 키는 키 없는 연결로 시험합니다. 응답 확인과 소요 시간을 표시하며, 제한 시간 초과는 서버 장애나 조사 실패를 뜻하지 않습니다.

## 확장 관리

- **분석 환경**: 설치된 도구와 환경을 확인하고 업데이트를 준비합니다.
- **확장팩**: 도구와 스킬 묶음의 내용·호환성을 검토한 후 사용할 버전을 선택합니다.
- **도구 제작**: 저장소 또는 소스 파일을 바탕으로 제작 요청을 준비합니다. 요청 저장과 실제 제작 시작은 구분됩니다.
- **스킬 제안**: 포식이가 제안한 반복 절차를 검토하고 등록·적용합니다.

새 사건 기본값과 현재 사건의 구성을 구분합니다. 변경 검토에는 대상과 적용 범위를 먼저 표시하고, 정확한 버전·해시는 상세 내역에서 확인할 수 있습니다. 다른 항목으로 이동하면 검토 중인 작업의 실행 버튼은 해당 항목에서만 나타납니다.

이전 `/management` 주소는 같은 조직·사건·대화 범위를 유지한 채 통합 설정으로 이동합니다. 최초 설치의 설정 안내는 그대로 제공됩니다. 설정 화면을 여는 동작은 조사 또는 모델 호출을 시작하지 않습니다.

## 동시 조사

새 조사 접수 한도는 호스트 전체에서 2개입니다. 진행·일시정지·접수 대기 중인 조사를 합산하며, 완료하거나 명시적으로 종료하면 자리가 생깁니다. 시작 화면과 새 조사 버튼에 현재 사용량을 표시합니다. 두 자리가 모두 사용 중이면 추가 접수를 막으며, 자동 대기열은 만들지 않습니다.

이 한도는 기존 새 사건 접수 정책을 확장한 것입니다. 기존 대화의 재개와 도구 실행은 Hermes의 세션별 실행·소유권 제어를 유지하며, 과거 완료 세션의 재활성화까지 제한하는 별도의 실행 스케줄러는 추가하지 않습니다. 각 사건의 자료·대화·목표는 분리됩니다.
